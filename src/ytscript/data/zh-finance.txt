# Vocabulary for a Mandarin US-market commentary channel.
#
# Two kinds of line:
#   term              seeds Whisper's prompt so it expects the word
#   wrong => right    also rewrites the word when it comes out mangled
#
# Both sides of a "=>" line are seeded, so a correction doubles as a term.
# Rewrites are literal. An ASCII left-hand side only matches as a whole word,
# so "CDS" never fires inside "CDSX". Order matters: the prompt is capped at
# a couple of hundred characters, and the file is read top down.
#
# Copy this file, edit it, and point `vocabulary` at your copy — the errors a
# model makes follow the speaker, so this list is worth growing as you read.
